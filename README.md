# Frontend Developer Portfolio

This is a modern, responsive personal portfolio website built with Next.js 14, TypeScript, and Tailwind CSS. It is designed to showcase my skills, projects, and professional background effectively.

## 🚀 Key Features

*   **Fully Responsive Design:** Mobile-first architecture ensuring seamless experience across desktops, tablets, and mobile devices.
*   **Project Showcase:** Interactive project cards with live demo links and GitHub repository links for each project.
*   **Skill Visualization:** A clean, visually appealing "Technical Skills" section highlighting proficiency with various technologies.
*   **Modern Navigation:** User-friendly mobile hamburger menu for easy site navigation.
*   **Performance-Oriented:** Built with Next.js for fast loading times and optimal SEO.
*   **Clean UI/UX:** Styled using Tailwind CSS with professional hover effects and consistent spacing.

## 🛠 Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Form Management:** `react-hook-form` & `zod`
*   **Iconography:** `react-icons`

## 📦 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
